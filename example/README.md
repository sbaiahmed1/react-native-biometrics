# Biometrics Example App

Demo app for [`@sbaiahmed1/react-native-biometrics`](../README.md), built with [Expo](https://expo.dev) using [Continuous Native Generation](https://docs.expo.dev/workflow/continuous-native-generation/) — the `ios/` and `android/` directories are generated by `expo prebuild` and are not committed. Native project configuration lives in [`app.json`](./app.json).

## Running

Install dependencies from the **repository root** (Yarn workspaces — npm does not work):

```sh
yarn
```

Then, also from the repository root:

```sh
yarn example ios       # build + run on the iOS simulator
yarn example android   # build + run on an Android emulator/device
yarn example start     # start Metro (dev client) on its own
```

The first `ios`/`android` run generates the native project and installs pods automatically. To regenerate from scratch (e.g. after changing `app.json`):

```sh
yarn example expo prebuild --clean
```

## Architecture coverage

The app intentionally runs the **new architecture on iOS** and the **old architecture on Android** (`ios.newArchEnabled` / `android.newArchEnabled` in `app.json`), so both of the library's native code paths and both JS event-emitter paths are exercised. Flip a flag and re-run `expo prebuild --clean` to test the other combination.

## What's inside

- **AuthExample** — sensor availability, simple prompts, authentication options
- **ColorExample** — themed prompt UI colors
- **CombinedBiometricsDemo** — key management, integrity validation, signatures
- **DebuggingExample** — diagnostics, debug logging, capability detection
- **BiometricChangeExample** — biometric change detection events (see [BIOMETRIC_CHANGE_DETECTION.md](../BIOMETRIC_CHANGE_DETECTION.md))

## Testing biometrics

- **iOS simulator**: enable Face ID via *Features > Face ID > Enrolled*, then *Matching Face* / *Non-matching Face* to answer prompts.
- **Android emulator**: enroll a fingerprint in system settings, then answer prompts with `adb emu finger touch 1`.
